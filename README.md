# ApaAdanyaShader

A custom realistic Minecraft shaderpack designed for Iris Shaders & Sodium (and OptiFine) on modern Minecraft.

## Features
- **Screen-Space Reflections (SSR)** for water and wet surfaces
- **Screen-Space Global Illumination (SSGI)**
- **Volumetric Clouds** with raymarching and multiple octaves of noise
- **Volumetric Light / God Rays**
- **Atmospheric Scattering** with dynamic day, sunset, and night celestial cycles
- **Bloom & ACES Filmic Tone Mapping**
- **Waving Foliage & Realistic Water Shading**

## Installation
1. Download or clone this repository.
2. Place the `ApaAdanyaShader` folder (or zip) into your `.minecraft/shaderpacks/` directory.
3. Open Minecraft, go to **Options -> Video Settings -> Shader Packs**, and select `ApaAdanyaShader`.
